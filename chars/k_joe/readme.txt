==========================================================
COMMAND BASICS
==========================================================

* LP + LK - "Hide defense"

* f + LP - "Hammer swing"

+ f + LK - "Spin kick"

* f + HP - "Parasol roll"

* f + HK - "Down kick"

* f or b + HP or HK (near enemy) - "Arm throw"

==========================================================
SPECIAL MOVES
==========================================================

* (Air OK) d, df, f, P - "Cutter boomerang"
Hold any direction to influence thrown arc
	
* d, db, b, P - "Smash punch / Vulcan jab"
LP is Smash Punch
HP is Vulcan Jab followed by a Smash Punch
	
* (Air) d, db, b, P - "Double kick"
Air variation of Smash Punch
	
* f, d, df, K - "Rising break"

* (Air) d, db, b, K - "Pin point kick"

* f, d, b, K - "Air drop"
Special throw

==========================================================
SUPER MOVES
==========================================================

* (LEVEL 1) d, f, d, f, P - "Wave beam"

* (LEVEL 2) d, f, d, f, PP - "Plasma wave cannon"

* (LEVEL 1) d, f, d, f, K - "Ultra-jet jump"

* (LEVEL 1) d, b, d, b, P - "Iron Mam helper"

==========================================================
BETA VERSION
==========================================================

Press start four times during the character intro to access a modified movelist. If done correctly, the character should flash and a confirmation sound should play. It's just some moves that were removed or changed over time.
The differences are:

* d, db, b, K - "Spin kick"
Replaces f + LK

* (LEVEL 1) d, f, d, f, K - "Super rising break"

* (LEVEL 1) d, b, d, b, P - "Multi-sword attack"
Replaces Iron Mam helper

* (LEVEL 1) f, d, b, K - "Super air drop"
Replaces Air drop
