Kudo=Helmet of The Karate Tournament By The_None

Note:This char is not suited for simul mode

Installation:
To install the character, extract the files into Mugen's "chars" directory (the files are stored in a sub-directory so if you extract it correctly the files would be in [mugen]/chars/helmet), edit the select.def found under the [mugen]/data directory as instructed in the file and.....
-Winmugen users (sort of deprecated), add the line:"helmet, stages/[name of stage].def" (without quotation marks, also applies to below)
-1.0 users, add the line:"helmet/helmet_10, stages/[name of stage].def"
-1.1 users, add the line:"helmet/helmet_11, stages/[name of stage].def"

Movelist:

==Command Moves==
-Counter mid:				Z
-Counter high:				B+Z
-Counter low:				D+Z

==Throws==
-Pass punch:				up close, B/F+Y
-Throw:					up close, B/F+B

==Special Moves==
-Blur Punch:				QCF+X
-Double Punch:				QCF+Y
-Double Dive:				QCB+A (also mid-air)
-360 Kick:				QCB+B
-Double Sweep:				QCF+A
-Double Kick:				QCF+B
-Crane Kicks:				DP+A
-Helicopter:				DP+B
-Cartwheel:				DP+Y

For 1 of drive stock (or 0.5 of power stock) you can canel special moves into each other
Reaching each of 3 power stocks increases the maximum drive stock.

==Super Moves==
-Dragon Kick:				QCB+A+B
-Meantime:				QCF+X+Y
-(Lv.3)Bad Mood:			QCB+X+Y
