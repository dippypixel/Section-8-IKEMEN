Bootleg Ryu (2.0)
by DrKelexo

=====     KEY     =====

X	-	Light Punch
Y	-	Heavy Punch
A	-	Light Kick
B	-	Heavy Kick
P   -   Any Punch
K   -   Any Kick

=====     COMMAND BASICS     =====

f + HP / HK     - Forward Throw
b + HK / HK     - Backward Throw
f + LK          - Overhead

=====     SPECIAL MOVES     =====

(A) means it can be performed in the air
(*) means it can be powered up by pressing both P/K buttons at once (ground only)

d, f + P    - Hadorken  (A) (*)
d, f + K    - BLADE!  (A) (*)
d, b + P    - Untouchable  (A) (*)
d, b + K    - Cat.Kick  (A) (*)
b, f + K    - Execute Hado Kick  (*)

=====     SUPER MOVES     =====

d, f, d, f + P      - (LVL1) Block Head
d, f, d, f + K      - (LVL1) Pasta Maker (A)
d, b, d, b + K      - (LVL1) Kick It!
Hold b, f, b, f + P - (LVL2) Air Force Two
