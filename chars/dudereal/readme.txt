DudeReal EX by The_None for Mugen 1.0/1.1

Note:Despite what one of his abilities would imply, this char is not suited for simul mode

Installation:
To install the character, extract the files into Mugen's "chars" directory (the files are stored in a sub-directory so if you extract it correctly the files would be in [mugen]/chars/dudereal), edit the select.def found under the [mugen]/data directory as instructed in the file and.....
-1.0 users, add the line:"dudereal/dudereal_10, stages/[name of stage].def"
-1.1 users, add the line:"dudereal/dudereal_11, stages/[name of stage].def"

The old WinMUGEN build is not supported.
