Installation:
To install the character, extract the files into Mugen's "chars" directory (the files are stored in a sub-directory so if you extract it correctly the files would be in [mugen]/chars/viper), edit the select.def found under the [mugen]/data directory as instructed in the file and.....
-Winmugen users, add the line:"senlieb, stages/[name of stage].def" (without quotation marks, also applies to below)
-1.0 users, add the line:"senlieb/senlieb10, stages/[name of stage].def"
-1.1 users, add the line:"senlieb/senlieb11, stages/[name of stage].def"

Movelist:

Command Moves:
-Overhead Punch:		B + MP
-Walking Pimpslap:		F + HP
-High Angle Front Kick:		B/F + LK
-High Angle Back Kick:		B/F + MK
-Throw:				up close, B/F + HK (also on air)
-Head toss/recall:		HP+HK
-Guard cancel Counter:		MP+MK (requires 1 power stock and head)

Special Moves (both modes):
-Earthquake:				Hold kick then release
-Evasion Roll:				Quarter Circle Backwards + Kick

Special Moves (with head):
-Fireball*:				Charge Back, Forward + Punch (also on air)
-Meteor Morph:				Charge Back, Forward + Kick (also on air)
-Phoenix Smash*:			Charge Down, Up + Punch
* - Denotes a move with EX version available (do the command with two punch/kick buttons)

Special Moves (Headless):
-Getting aHead*:			Charge Back, Forward + Punch
-Scissor Kick*:				Charge Back, Forward + Kick
-Cool as Ice:				Charge Down, Up + Punch
* - Denotes a move with EX version available (do the command with two punch/kick buttons)
