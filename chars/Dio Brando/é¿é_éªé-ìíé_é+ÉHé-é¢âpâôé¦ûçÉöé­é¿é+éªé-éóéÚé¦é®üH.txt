AIについて
MUGENのdataファイル内のselect.def内の登録名を1st DIOから1st DIO/0011-AI.defに変更することでAIが入ります

・AIレベル
0011-AI フォルダ内の1stDIO.cns内で「AIレベル」を検索して、

[state -3, AIレベル]
type = VarSet
trigger1 = var(59) = 1
trigger1 = roundstate = 2
v = 57
Value = 9    +ifelse((life = [600,1200]),(var(57) != 11),0)
;       ↑1～11の値で変更　デフォルトは9

の Value =  の最初の数字のみを変更してください

・AI即起動スイッチ
0011-AI フォルダ内の1stDIO.cmd内で「AI即起動スイッチ」を検索して、

;Trigger15 = 1;AI即起動スイッチ
を ; をとって
Trigger15 = 1;AI即起動スイッチ
にしてください

声について

ディオの声を子安ボイスと緑川ボイスから選ぶことが出来ます

変え方

①_config.cnsファイルを開く
②ボイス設定の部分を

var(13) = 0
だと子安ボイス

var(13) = 1
だと緑川ボイス

に変える
