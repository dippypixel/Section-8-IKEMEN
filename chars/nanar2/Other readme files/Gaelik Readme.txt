MOVELIST :

System :

a+x : dodge.

b+y : charge.

c+z : Blow Out.

x+y or y+z or a+b or b+c : Throw.

Specials :

D,DF,F,x (y or z) : Hitman's shotgun.

F,D,DF,x (y or z) : Barbell's first try.

D,DB,B,x (y or z) : Genocide Chainsaw.

D,DB,B,x -> D,DB,B,y -> D,DB,B,z : Triple Genocide Chainsaw.

B,D,DB,x (y or z) : Dodge to Fall.

D,DF,F,a -> D,DF,F,b -> D,DF,F,c : Cannon Kick.

D,DB,B,a (b or c) : Ballerine Kung-Fu Kick.

Supers :

D,DF,F,x+y or y+z : Hitman's M60.

F,D,DF,x+y or y+z : Barbell's first fly.

D,DB,B,x+y or y+z : Madness Chainsaw.

B,D,DB,x+y or y+z : Turkish Hype.

D,DF,F,a+b or b+c : Silly Cannon.

D,DB,B,a+b or b+c : Incredible Ballerine Kick.

Gigas :

D,DF,F,D,DF,F,x (y or z) : 100-Punches of Despair.

D,DB,B,D,DB,B,x (y or z) : Burp Up !

D,DF,F,D,DF,F,a (b or c) : AAAAAAH ! Spider !

D,DB,B,D,DB,B,a (b or c) : Biokidz Force.

Tetra : D,DF,F,D,DF,F,c+z

Final Attack : D,DB,B,DB,D,DF,F,DF,D,DB,B,DB,D,DF,F,Start (!!!) (Anti-Cheap Mode only).
