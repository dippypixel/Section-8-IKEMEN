COMMAND LIST:

--SPECIALS--

* The Dance: D, DF, F, (punch)
Button changes distance and increases startup.
Can be used on the ground.

* Gunshot: D, DB, B, (punch)
Can be used on the ground and in the air.

* Saber Swing: D, DF, F, (kick)
A - High Swing
B - Trip Poke
C - Anti-Air Slash
Can be used on the .

* Wall Launch: D, DB, B, (kick)
Must be close to the wall.
After clinging to the wall, press (kick)
Holding down makes you fall faster from the wall.
Button press changes distance sacrificing damage.
Can be used on the ground and in the air.

--HYPERS--

* Blind Rage: D, DF, F, D, DF, F, (punch)
Costs 1000 Power
Can be used on the ground.

* Souls of the Punished: D, DB, B, D, DB, B, (punch)
Costs 1000 Power
Can be used on the ground.

* Release the Teeth Guy!: D, DF, F, D, DF, F, (kick)
Costs 2000 Power
Can be used on the ground.

* Punishment Day: D, DB, B, D, DB, B, (kick)
Costs 3000 Power
Can be used on the ground.
