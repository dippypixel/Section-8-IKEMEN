------------------------------------------------------------------------------
　　　　　　　　　　　　　　使い方と説明
------------------------------------------------------------------------------
普通に使う場合は、フォルダの中のduagi-AIフォルダをキャラ本体のフォルダに入れて、
一緒に入っている"Nameless/Nameless(duagi).def"を"Nameless.def"に変更し上書きしてください。


他のAI製借者様と併用したい場合は、duagi-AIフォルダをキャラ本体のフォルダに入れて、
フォルダの中のNameless(duagi).defをキャラ本体のフォルダに移してください。
data内に有るselect.defを開きNameless/Nameless(duagi).def
と登録すればおｋです。

＊pal7～12で常時AIにできます。


AIの強さを１～10の間で変えることができます。
レベル6からはガードや技の反応が鋭くなってきます（デフォルトは10)。

変更の方法は、Nameless-AI.cnsファイルを右クリック→編集でひらいて
[Statedef -2]の

;===========================================================================
;                    　  AIレベル設定用記述
;===========================================================================
[State -2,AI Level]
type = varset
trigger1 = var(59)=-1
trigger2 = palno = [7,12]
;trigger3 = roundstate = 2 && ctrl

var(59) = 10;ここを設定
の　　　　↑
　　　ここの数字を変えて調節してください。

      var(59)の数値の変更でAIレベルが変化します。
      レベルの幅は1～10。10が最高レベルです。
      trigger3の前の「;」を消すとAI常時起動になります。
      対戦するときや動画を撮る時など、常時AIにしたいときは ";trigger16 = 1" の左端の";"を消してください。
      7P～12Pカラーでも常時AIになります。



＊超反応うぜぇ！という人は設定で変更可能です。
　封印したい人は、Nameless-AI.cnsファイルのAIレベル設定用記述の下の記述の、

;超反応スイッチ
[State -2,tc]
type = varset
triggerall = var(59)>0
trigger1 = 1

var(55) = 1       ; 1:超反応あり / 0:超反応なし

の　　　　↑
　　　ここの数字を変えて調節してください。
      デフォルトは超反応ありです。



＊AIの受け身をcanrecover時限定にするように設定ができます。
  超反応スイッチの下の、

;AI受け身canrecoverスイッチ
[State -2,AI ukemi]
type = varset
triggerall = var(59)>0
trigger1= 1

var(40) = 1       ; 1:canrecover無視(本体記述そのまま) / 0:canrecoverで受け身
の　　　　↑
　　　ここの数字を変えて調節してください。
      デフォルトはcanrecover無視(本体記述そのまま)です。
