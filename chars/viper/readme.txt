Viper from Survival Arts by The_None

A Wealthy Street Fighter enters the Mugen Tournament to make evne more money!

Features:
-All the moves from the original
-Three weapons
-Throw teching
-Unique hitpauses

Features exclusive to this mugen conversion:
-Juggles (by the by, each move in itself can only juggle once)
-A bit looser basic comboability
-Better collision detection
-Super moves
-Counter hits that reward with slightly longer hitstuns
-Being able to drop weapons without picking up another/getting hit

Features from the source I did not bring over for a reason:
-High Damage Output
-Being able to pick up weapons of the other Viper/Mass's Hiryu
-Almost all of the "Fatalities"

Changes since the 2014 release:
-Assigned the postype to the floor bounce explods in custom states so the spark from the opponent getting hammered by the Lv.3 super now displays at correct position in Mugen 1.1
-Reripped few sounds
-Ripped the blood hit the floor effects from the actual game rather than using the Battle Monsters effect
-Fixed the triggers for the First Attack monit
-Made the spiral fireball reflectable with Vans's projectile reflection system
-Tweaked the way the AI uses the Iron Wild Maiden Hair and also slightly increased it's damage

Installation:
To install the character, extract the files into Mugen's "chars" directory (the files are stored in a sub-directory so if you extract it correctly the files would be in [mugen]/chars/viper), edit the select.def found under the [mugen]/data directory as instructed in the file and.....
-Winmugen users, add the line:"viper, stages/[name of stage].def"
-1.0 users, add the line:"viper/viper_10, stages/[name of stage].def"
-1.1 users, add the line:"viper/viper_11, stages/[name of stage].def"

-Dash Elbow:			Forward, Forward+Punch
