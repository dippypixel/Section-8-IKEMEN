Dantel from Survival Arts by The_None

Dantel founded Survival Arts for the purpose of eating the flesh of powerful human beings in order to gain immortality. He has made his disciples fight against each other tahn choose a successor.

Installation:
To install the character, extract the files into Mugen's "chars" directory (the files are stored in a sub-directory so if you extract it correctly the files would be in [mugen]/chars/dantel), edit the select.def found under the [mugen]/data directory as instructed in the file and.....
-Winmugen users, add the line:"dantel, stages/[name of stage].def"
-1.0 users, add the line:"dantel/dantel_10, stages/[name of stage].def"
-1.1 users, add the line:"dantel/dantel_11, stages/[name of stage].def"
