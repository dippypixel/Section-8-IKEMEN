=====	"JIMMY SHAKER DAY" INPUT FOLLOWUPS	=====

During Jimmy Shaker Day, press any of the 6 buttons to add attacks into a chain. If you input a specific set of attacks, you'll get certain followups. If you don't have the meter for a followup that requires it, the default ender is used instead.

X Y Z X Y Z   - (LVL1) Pillar of Davidson
Z Z Z C B A   - (LVL1) Switchback (Detroit 2000)
A B C A B C   - (LVL1) Stellar
X A X A X A   v
A X A X A X   - (LVL1) Carpe Diem
X A Y B Z C   - (LVL1) Schizophrenia
X X Y Y Z Z   - (LVL2) Shoot Em Up
A B A B A C   - (LVL2) Everything's Ruined
B Y Y B B Y   - (LVL2) Even Flow
